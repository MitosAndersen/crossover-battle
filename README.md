# クロスオーバーバトル

ブラウザだけで遊べる、ターン制のパーティバトルゲームです。
インストール不要で、下のURLを開けばすぐ始められます。

**▶ [遊ぶ](https://mitosandersen.github.io/crossover-battle/)**

## 特徴

- 31作品・136人のキャラクターから3人を選んでパーティを編成
- 408種類のスキルと、ロール（アタッカー／サポーター／タンク／ストライカー）による役割分担
- 通常敵・中ボス・大ボス あわせて112体
- 周回するほど強くなる敵、道中で拾えるレリック、実績システム
- PC・スマートフォンの両方に対応

## 動かし方

外部ライブラリを一切使っていないので、`index.html` をブラウザで開くだけで動きます。
ビルドもインストールも不要です。

```
index.html      画面の骨組み
style.css       見た目
js/
  main.js         ゲーム進行の制御
  battle.js       戦闘ロジック
  ui.js           描画
  characters.js   キャラクターデータ
  skills.js       スキルデータ
  relics.js       レリック
  passives.js     パッシブ
  achievements.js 実績
  audio.js        効果音・BGM（ファイルではなくコードで合成）
```
